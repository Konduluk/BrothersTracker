# Brothers Tracker — первая тестовая версия

⚠️ **Это прототип, а не проверенная на живом сайте программа.** Парсер нужно подтвердить на реальном тексте страницы. Текущая версия сохраняет замеры и показывает прирост от первого замера, но пока **не реализует конкурсы, экспорт Excel и надёжный учёт выходов/возвращений**. Не используйте её для окончательного распределения призов.

## Как загрузить в GitHub

В репозитории нажмите **Add file → Upload files** и загрузите **содержимое** этого архива. Важно сохранить путь `.github/workflows/windows.yml` (при загрузке через веб-интерфейс GitHub скрытые папки и вложенные пути могут потребовать отдельных действий). Удобнее всего загрузить проект с ПК через GitHub Desktop или веб-редактор github.dev, сохранив структуру каталогов. После коммита откройте **Actions → Build Windows EXE → Run workflow**. Когда сборка завершится, скачайте артефакт **BrothersTracker-Windows**.

## Как запустить браузер мониторинга

1. На ПК с Windows установите Chrome или Edge, если их ещё нет.
2. Используйте `start-monitor-browser.bat` из этого проекта. Он запускает отдельный Chrome с локальным портом отладки и постоянным профилем в `%LOCALAPPDATA%\BrothersTracker\chrome-profile`.
3. В этом окне самостоятельно войдите в игру и откройте `http://87.228.3.220/brotherhood/warriors`. Оставьте **одну** вкладку.
4. Запустите `BrothersTracker.exe`, нажмите «Считать сейчас» для первого теста.
5. Если программа не распознала список, **не продолжайте мониторинг**: потребуется адаптация парсера под фактический текст страницы.

Chrome 136+ требует отдельного пользовательского профиля для remote debugging. Не используйте повседневный профиль. Порт привязан к `127.0.0.1`; не открывайте его наружу. Не передавайте никому файлы профиля браузера: они могут содержать действующую авторизацию.

Программа **не управляет основным игровым браузером**. При закрытии программы окно Chrome мониторинга остаётся открытым.

## Ограничения

- Вкладка мониторинга перезагружается перед каждым замером.
- Сессия может истечь; тогда потребуется повторный вход.
- Проверка полноты списка пока эвристическая, без достоверного признака окончания загрузки.
- Автоматический сбор может нарушать правила игры; проверьте их перед использованием.
- Время фиксируется в локальном часовом поясе Windows.
- GitHub Actions создаёт Windows EXE, но запуск на пользовательском ПК и чтение сайта не проверены.
